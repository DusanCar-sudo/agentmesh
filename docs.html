Overview

AgentMesh is a multi-agent orchestration framework in Python. An orchestrator decomposes goals into subtasks, dispatches them to specialized AI agents, and recursively learns from outcomes.

It has two entry points: a CLI harness (run.py) and a FastAPI backend (server.py) with a visual workflow builder.

Agent Execution Flow

  1. Orchestrator calls LLM to decompose goal into 2–4 ExecutionContract tasks with parallel groups.
  2. Tasks are dispatched to agents: parallel within a group, sequential between groups.
  3. Each agent runs a tool loop: LLM decides tool calls → registry executes → results fed back.
  4. After task: episode stored in SQLite, RecursiveLearner may evolve the agent's system prompt.
  5. After full cycle: HarnessOptimizer rewrites the orchestrator's decomposition strategy.

Memory System

AgentMesh uses a 4-layer SQLite-backed memory:

  • Episodic — per-task execution traces
  • Semantic / Lessons — extracted learnings
  • Procedural / Skill Stats — tool usage outcomes
  • Working — transient agent state

State is file-backed, so agent memory survives truncation, restart, and delegation.

Skills

The skill registry provides built-in tools that agents can call:

  • web_search
  • http_get
  • read_file
  • write_file
  • run_python
  • list_files

Additional skills can be added as JSON definitions in skills/ and are auto-discovered at runtime.

Server / API

server.py is a standalone FastAPI app. It powers the visual workflow builder and uses its own RecursiveLearner with episodes stored in hermes_memory.json.

terminal
$ uvicorn server:app --host 0.0.0.0 --port 8000 --reload

Key Design Decisions

  • Tight token budgets per agent contract — research shows same quality at 13x less cost.
  • Hard boolean completion gates instead of verifier agents — verifier agents hurt performance by -8.4.
  • Raw traces never summarized — Stanford finding: summaries drop accuracy from 50% to 34.9%.
  • Recursive self-evolution — agents diagnose own failures, extract lessons, evolve system prompts. Acceptance gate rejects generic lessons.
  • File-backed state — agent working memory on disk, survives truncation/restart/delegation.
