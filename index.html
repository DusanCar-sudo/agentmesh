Quickstart

Get your first AgentMesh node running in 2 minutes.

terminal

# Install via pip

pip install agentmesh

# Or via npm

npm install @agentmesh/sdk

# Initialize your first mesh node

agentmesh init --name my-first-node

# Start the node

agentmesh start

How It Works

A fully decentralized mesh with no central coordinator, designed for resilience and scale.

1

Node Discovery

Nodes automatically find and connect to peers on the local network or via public relay servers.

2

Message Routing

Agents send messages to the mesh, which automatically routes them to the target agent via the fastest available path.

3

Fault Recovery

If a node goes offline, the mesh automatically re-routes messages through alternative peers with zero downtime.
